# Data

Put the released Molecular Twin supplementary dataset here:

    43018_2023_697_MOESM3_ESM.xlsx      md5 271f8b25cbcb75ed5818d61a5151a1d3

Download: Supplementary Data 3 of Osipov et al., "The Molecular Twin
artificial-intelligence platform integrates multi-omic data to predict outcomes
for pancreatic adenocarcinoma patients", Nature Cancer 5, 299–314 (2024),
https://www.nature.com/articles/s43018-023-00697-7

The file is not redistributed here. It holds 74 patients, 6,361 columns
(`Biobank_Number`, `label_deceased`, `label_days_to_death` and 6,355 features in
ten analyte blocks). There is no missing cell inside any analyte block; a
patient either has an analyte in full or not at all.

Released source code (not redistributed): Zenodo record 8423595,
https://zenodo.org/records/8423595, file `MTPilot_multiomic_model_training.py`.
